# CRYPTO slot loop

The work itself is the tick list: [`BUILD.md`](BUILD.md).

Every CRYPTO slot:

1. Next unchecked BUILD line
2. Append the standing series (`onchain/btc_d.csv` until you leave that list)
3. One sentence in `research/`
4. Stop

Tue 14:30–19:00: new file or first pull.  
Wed 10:30–13:00: append + observation. Townhall claim → `articles/` if it is a claim; into the CSV if it is a number.

Z is optional. Pull fails: pipeline only. No sentence required.
